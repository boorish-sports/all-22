Privacy policy

All-22 Film Search, Chrome extension. Effective 2026-09-09.

The short version: the extension collects nothing and sends nothing to its author. There are no accounts, no analytics, no telemetry, no crash reporting, and no third-party services other than the two it needs to function, described below.

What is stored on your device

  • The play index. A read-only SQLite database of public nflverse play-by-play data (about 90 MB) is cached in the extension's IndexedDB so it is downloaded once, not every time.
  • A game-ID map. When you open a clip, the extension learns which NFL Pro game identifier corresponds to which nflverse game and keeps that mapping in chrome.storage.local so it need not ask again.
  • UI preferences. Whether you have dismissed the first-run notice, your playback speed, and similar settings, in chrome.storage.local.
  • Your cutups and notes. The plays you save into cutups and the notes you write on plays, in chrome.storage.local.

Removing the extension deletes all of this. None of it leaves your browser unless you choose to share a cutup: Copy link puts the cutup's name, its play IDs and your notes on those plays into a link on your clipboard. The data is in the part of the link after #, which browsers do not send to the site, so it reaches only the people you give the link to.

Network requests the extension makes

  • GitHub (github.com/boorish-sports/all-22-index and GitHub's release-asset hosts). To download the play index and, on later runs, to check whether a newer index exists. GitHub sees this request the way it sees any download; the extension sends no identifying information.
  • NFL Pro (pro.nfl.com). When you click a play, the extension asks NFL Pro for that clip using the same requests NFL Pro's own film room makes, under your own logged-in session. The same goes for a search that uses an NFL Pro filter (marked NFL PRO in the panel): the extension sends that one film-room query, as NFL Pro's own film room does when you set a filter there. While the On field list is showing (always in the wide view, in the half view only when you open it), each play you open also asks NFL Pro who was on the field for it. NFL therefore sees which clips you open and which NFL Pro filters you search with, exactly as it would on the site. Searches that use only the local index send nothing. The extension makes no NFL request you did not start by selecting a play or running such a search; it does not prefetch, poll, or enumerate.

The panel's tip-jar button is an ordinary link: clicking it opens this site's tip section in a new tab. Nothing from Ko-fi or any other site is loaded into the panel.

What the extension does not do

  • It does not collect, transmit, or sell personal information, browsing history, or search terms. The one exception is the NFL Pro filters described above, which NFL Pro sees because it answers them.
  • It does not download, copy, cache, or re-host video.
  • It does not read or store your NFL Pro credentials. It uses the page's own session.
  • It does not run on any site other than pro.nfl.com.
  • It does not load remote code. The index it downloads is data, verified against a SHA-256 checksum before it is opened.

Permissions, in plain terms

  • storage and unlimitedStorage: to keep the 90 MB index, the small settings above, and your cutups and notes on your device.
  • offscreen: to run the SQLite engine in a background document, which Chrome requires for WebAssembly outside a page.
  • Host access to pro.nfl.com: to add the search panel to the film room and fetch the clips you click. Host access to the GitHub hosts named above: to download the index.
